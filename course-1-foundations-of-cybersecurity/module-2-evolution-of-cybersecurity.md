# Module 2: The Evolution of Cybersecurity

## Key Concepts

- The cybersecurity field is constantly evolving, driven by international hacks and the growing need to protect organizations and individuals.
- Many present-day attacks aren't new — they're enhanced versions of previous attacks. Understanding historical attacks provides valuable insight into current threats.
- **Virus**: malicious code designed to interfere with computer operations and damage data or software.
- **Malware**: software created to harm devices or networks (viruses fall under this broader category).

## Notable Historical Attacks

| Attack | What Happened | Impact / Legacy |
|---|---|---|
| **The Brain Virus** | Created to track illegal software copies, but spread globally by infecting disks | Slowed productivity and impacted business operations; created the need for formal security and productivity plans |
| **The Morris Worm** | Created to assess the size of the internet, but continuously reinstalled itself, crashing computers | Led to the establishment of **CERTs** (Computer Emergency Response Teams) |
| **The Love Letter Attack** | First major example of a social engineering attack — exploited users' trust in unsolicited emails | Infected 45 million computers |
| **The Equifax Breach** | Unaddressed vulnerabilities in the credit reporting agency exposed personal data | Over 143 million customers' personal information exposed; emphasized the need for preventive security measures |

> Because of the constant evolution of attacks, the industry established dedicated response teams called **CSIRTs** (Computer Security Incident Response Teams).

## Common Methods of Attack

### Phishing
Uses digital communication to trick people into revealing sensitive data or deploying malicious software.

| Type | Description |
|---|---|
| **Business Email Compromise (BEC)** | Email appearing to come from a known source, making a seemingly legitimate request to gain a financial advantage |
| **Spear phishing** | Malicious email appearing to come from a trusted source, targeting a specific user or group |
| **Whaling** | A form of spear phishing that targets company executives specifically |
| **Vishing** | Exploiting voice communication to obtain sensitive info or impersonate a known source |
| **Smishing** | Using text messages to trick users into revealing sensitive info or impersonate a known source |

### Malware
Software designed to harm devices or networks.

| Type | Description |
|---|---|
| **Viruses** | Malicious code that hides, infects, then damages/destroys data — spread via malicious attachments or downloads |
| **Worms** | Self-replicating malware that spreads from an infected device to others on the same network without user action |
| **Ransomware** | Encrypts an organization's data; attackers demand payment to restore access |
| **Spyware** | Gathers and sells information without consent — e.g., private emails, texts, voice/image recordings, location data |

### Social Engineering
A manipulation technique that exploits human error to gain private information, access, or valuables — built on false trust and deception.

| Type | Description |
|---|---|
| **Social media phishing** | Attacker gathers target details from social media before initiating an attack |
| **Watering hole attack** | Targets a website frequently visited by a specific group of users |
| **USB baiting** | A malware-loaded USB is left for an employee to find and plug in, unknowingly infecting the network |
| **Physical social engineering** | Attacker impersonates an employee, customer, or vendor to gain unauthorized physical access |

## Why Social Engineering Works

- **Authority** — impersonating someone with power
- **Intimidation** — bullying tactics
- **Consensus/Social proof** — exploiting the belief that "others are doing it too"
- **Scarcity** — implying goods/services are in limited supply
- **Familiarity** — building a fake emotional connection
- **Trust** — building an emotional relationship exploited over time
- **Urgency** — pressuring quick action without question

## Training Employees Against Social Engineering

- Define what social engineering is, with examples
- Teach recognition of common tactics: phishing emails, baiting, pretexting
- Train employees to spot suspicious emails, messages, or calls
- Establish a clear process for reporting suspected attempts
- Provide regular refreshers on new/emerging threats
- Run simulated phishing exercises

## Managing a Data Breach Effectively

1. **Stay calm and composed** — panic undermines effective decision-making and leadership
2. **Contain the breach immediately** — e.g., shutting down servers, data centers, or communication channels to stop further unauthorized access or data exfiltration
3. **Follow the incident management plan** — investigate the breach thoroughly once contained

## The Eight CISSP Security Domains

| Domain | Focus |
|---|---|
| **Security and Risk Management** | Setting security goals, mitigating risk, ensuring regulatory compliance, maintaining business continuity |
| **Asset Security** | Protecting digital and physical assets — proper data handling across its lifecycle (storage, maintenance, retention, secure disposal) |
| **Security Architecture and Engineering** | Optimizing security via tools, systems, and processes (e.g., configuring firewalls) |
| **Communication and Network Security** | Securing physical networks and wireless communication |
| **Identity and Access Management (IAM)** | Managing/validating access to physical and logical assets; documenting access roles |
| **Security Assessment and Testing** | Testing security controls, analyzing data, performing audits to catch risks/vulnerabilities |
| **Security Operations** | Investigating incidents and implementing preventive measures |
| **Software Development Security** | Promoting secure coding practices in collaboration with dev teams |

## Attack Types

| Type | Description |
|---|---|
| **Password attack** | Attempts to access password-protected systems/data (e.g., brute force, rainbow table attacks) |
| **Social engineering attack** | Manipulation exploiting human error (phishing, smishing, vishing, spear phishing, whaling, BEC, etc.) |
| **Physical attack** | Security incidents affecting the physical environment (malicious USB cables/drives, card cloning, skimming) |
| **Adversarial AI** | Manipulating AI/ML technology to conduct attacks more efficiently |
| **Supply-chain attack** | Targets systems/hardware/software to find a vulnerability where malware can be deployed |
| **Cryptographic attack** | Targets secure communication between sender and intended recipient |

## Threat Actor Types

- **Advanced Persistent Threats (APTs)** — highly skilled, access networks without authorization; motives include damaging critical infrastructure or stealing intellectual property
- **Insider threats** — abuse authorized access to cause harm; motives include sabotage, corruption, espionage, or unauthorized data leaks
- **Hacktivists** — driven by political agendas; use digital tools for demonstration, propaganda, social change campaigns, or fame

## Hacker Types

- **Authorized (ethical) hackers** — follow a code of ethics and the law; conduct organizational risk evaluations
- **Semi-authorized hackers** — researchers who search for vulnerabilities but don't exploit them
- **Unauthorized (unethical) hackers** — break the law; aim to collect and sell confidential data for financial gain
- Some hackers work **both** ethically and unethically depending on the contract they take
- **Vigilante hackers** — consider themselves protectors, acting against unethical hackers
