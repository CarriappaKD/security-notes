# Module 4: Cybersecurity Tools and Programming Languages

## Cybersecurity Tools

| Tool | What It Does | Examples |
|---|---|---|
| **SIEM** (Security Information and Event Management) | Collects and analyzes security-related data (e.g., log data) in real time to monitor critical activity and identify breaches. Manually filtering through logs takes far too long — SIEM tools reduce that time significantly and surface alerts, often visualized on a dashboard. | Splunk, Google Chronicle |
| **Network Protocol Analyzers** (a.k.a. packet sniffers) | Capture and analyze data traffic flowing across a network. | tcpdump, Wireshark |
| **Playbooks** | Manuals detailing how to respond to a specific security incident. Every organization maintains multiple playbooks documenting the processes and procedures to follow for different scenarios. | — |

## Programming Languages and Operating Systems

**Linux** — an open-source operating system that primarily uses a command-line interface for interaction. Widely used in security work to examine logs and investigate system activity.

**Programming** — the process of creating a specific set of instructions for a computer to execute a task.

- **Python** — handles repetitive, time-consuming tasks that require high detail and accuracy, reducing human error and saving significant time. Commonly used for automating security tasks and building security tools.
- **SQL** (Structured Query Language) — used to create, interact with, and retrieve specific information from large databases.

## Key Terminology

| Term | Definition |
|---|---|
| **Web vulnerability** | A unique flaw in a web application that a threat actor could exploit using malicious code to gain unauthorized access, steal data, or deploy malware |
| **Antivirus software** | A software program used to prevent, detect, and eliminate malware and viruses |
| **Intrusion Detection System (IDS)** | An application that monitors system activity and alerts on possible intrusions; can also detect theft and unauthorized access |
| **Encryption** | The process of converting data from a readable format into a cryptographically encoded format, making it unreadable and difficult to decode for unauthorized users |
| **Penetration testing (pen testing)** | A simulated attack, performed with the organization's permission, to identify vulnerabilities in systems, networks, websites, applications, and processes |

> Every organization builds a different toolkit depending on its specific security needs — there's no single "standard" set of tools used everywhere.
